# Open-Source Research and Digital Curation: A Student Guide

A curated, plain-English archive of free, open-source and selected free proprietary tools for students.

## Run it on your own computer

```bash
npm install
npm run dev
```

## Add a tool

Edit `src/data/tools.json`. Every page is built from that file, so no component needs to change.
A category only appears on the site once at least one tool uses it.

Pushing to `main` publishes the site through GitHub Actions.
